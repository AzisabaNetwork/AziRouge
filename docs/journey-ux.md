# 出発・帰還の導線

準備中（初回ロビーを含む）はホームの出入口へ入ると、既存の深さ選択ダイアログが開きます。現在のプリセットを使用し、画面にはプリセット名を表示しません。出発確定後、生成に成功した場合だけ本人が探索へ移動します。仲間は出入口から同じ探索へ参加できます。帰還側は画面を挟まず移動します。

Esc・閉じるで準備に戻れます。出入口の外から入り直すまで選択画面は再表示しません。死亡・切断・リロードで出発操作を無効化し、ラウンドやセッションが変わった画面からの開始も拒否します。購入確認も元のセッション・フェーズ・ラウンドに限定します。

## 現地の目印

発光ItemDisplayとTextDisplayで「出発！」「帰還！」「旅支度」を表示します。出入口の位置は既存の `portals` 設定、ショップはホーム内の村人を使用します。メニュー操作・ボス挑戦のタグを持つ村人は除外します。常時パーティクルや繰り返しのチャット案内はありません。

`journey.enabled` は現地表示、`journey.entrance-height` は出入口範囲の上端からの高さ、`journey.view-distance` は表示距離（4〜64ブロック）です。文言は `messages.yml` の `journey` で変更できます。既存の設定ファイルに追加しなくても既定値で動作します。

初回のホーム・商人・探索・帰還の補足はプレイヤーのPersistentDataContainerに保存し、各一度だけアクションバーに表示します。メニューの「旅の手引き」から説明を再確認できます。購入自体は出発条件ではありません。

## 検証

自動テスト：出発可能な状態、準備・終了処理中の開始拒否、深さの欠損・非数・無限大・端数・範囲外を検証します。

実機確認項目（この環境では未実施）：

- 初参加でショップを利用でき、出入口の画面で深さと維持費を確認できる。
- Esc後にその場で動いても再表示せず、入り直すと開く。
- 2人が同時に確定してもラウンドが1つだけ開始する。後から確定した人は再入場で参加できる。
- 出発・帰還のタイトルと音が短く、表示が通路や商人へのクリックを邪魔しない。高さは実際のホーム形状に合わせて調整する。
- 帰還は即時に行われる。終了確認中に仲間の帰還・再出発があれば、更新した人数で確認をやり直す。
- 生成失敗時はホームに残る。転送がキャンセルされた場合は短い失敗表示が出て再試行できる。
- 古い購入確認から別フェーズの価格で購入できない。
- 初回補足は再接続しても繰り返されず、「旅の手引き」から再確認できる。
- 終了・リロード・チャンクの再読み込み後に目印が重複・残留しない。

通常ビルドにはbuild.gradle指定のShadow 8.3.11などの依存取得が必要です。今回の環境ではShadowを解決できず、代替としてキャッシュ済みライブラリによるJava 21向け全ソースコンパイルとJUnit実行を使用しました。これは配布用Shadow JARのビルド成功を意味しません。
