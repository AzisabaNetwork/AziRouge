# 出発・帰還の導線

準備中（初回ロビーを含む）はホームの出入口へ入ると、深さ選択ダイアログが開きます。深さはラウンドごとに選び、プレイヤーがプリセットを指定する導線はありません。出発確定後、生成に成功した場合だけ本人が探索へ移動します。仲間は出入口から同じ探索へ参加できます。帰還側は画面を挟まず移動します。

Esc・閉じるで準備に戻れます。出入口の外から入り直すまで選択画面は再表示しません。死亡・切断・リロードで出発操作を無効化し、ラウンドやセッションが変わった画面からの開始も拒否します。購入確認も元のセッション・フェーズ・ラウンドに限定します。

## 現地の目印

発光ItemDisplayとTextDisplayで「出発！」「帰還！」「旅支度」「納品箱」を表示します。出入口の位置は既存の `portals` 設定、納品箱は `economy.quota.delivery-chest`、ショップはホーム内の村人を使用します。メニュー操作・ボス挑戦のタグを持つ村人は除外します。常時パーティクルや繰り返しのチャット案内はありません。

`journey.enabled` は現地表示、`journey.entrance-height` は出入口範囲の上端からの高さ、`journey.view-distance` は表示距離（4〜64ブロック）です。文言は `messages.yml` の `journey` で変更できます。既存の設定ファイルに追加しなくても既定値で動作します。

初回のホーム・商人・探索・帰還・納品箱・ベッドの補足はプレイヤーのPersistentDataContainerに保存し、各一度だけアクションバーに表示します。メニューの「旅の手引き」から説明を再確認できます。購入自体は出発条件ではありません。

## 納品と就寝

宝はホームの納品箱へ入れた分だけ精算され、価格が共有資金へ加算されます。インベントリ内の宝は納品扱いになりません。スコアボードには現在の納品価格、ノルマ、連続未達によるゲームオーバーまでの残回数、深夜までの残り時間を表示します。

ラウンドは朝に開始します。生存者の半数以上が深い睡眠に達して設定秒数が経つか、全員が深く眠ると、通常の夜明けを経て同じ深さ設定で次ラウンドが自動開始します。ホーム内では昼でも雷雨に切り替えて就寝できます。深夜までに眠っていないプレイヤー、または帰還できていないプレイヤーは死亡扱いです。

## 検証

自動テスト：出発可能な状態、準備・終了処理中の開始拒否、深さの欠損・非数・無限大・端数・範囲外を検証します。

実機確認項目（この環境では未実施）：

- 初参加でショップを利用でき、出入口の画面で深さとノルマを確認できる。
- Esc後にその場で動いても再表示せず、入り直すと開く。
- 2人が同時に確定してもラウンドが1つだけ開始する。後から確定した人は再入場で参加できる。
- 出発・帰還のタイトルと音が短く、表示が通路や商人へのクリックを邪魔しない。高さは実際のホーム形状に合わせて調整する。
- 帰還は即時に行われ、納品箱とベッドの案内が表示される。
- 生成失敗時はホームに残る。転送がキャンセルされた場合は短い失敗表示が出て再試行できる。
- 古い購入確認から別フェーズの価格で購入できない。
- 初回補足は再接続しても繰り返されず、「旅の手引き」から再確認できる。
- 納品箱に入れた価格だけが共有資金とノルマ判定に使われ、インベントリ内の宝は残る。
- 50%就寝の待機時間、100%就寝の即時スキップ、深夜の強制終了と未就寝者の死亡扱いが機能する。
- 終了・リロード・チャンクの再読み込み後に目印が重複・残留しない。
